# Fermi-Dirac Distribution

A Python-based computational study of the Fermi-Dirac distribution and its temperature dependence in semiconductor physics.

## Project Overview

This project explores the Fermi-Dirac distribution, which describes the probability that an available energy state is occupied by an electron at thermal equilibrium.

## Objectives

- Understand the Fermi-Dirac distribution.
- Investigate how temperature affects electron occupation probability.
- Visualize the distribution at different temperatures using Python.

## Tools

- Python
- NumPy
- Matplotlib

## Theory

The Fermi-Dirac distribution is given by:

\[
f(E) = \frac{1}{1 + \exp\left(\frac{E-E_F}{k_B T}\right)}
\]

Where:
- \(f(E)\): Probability that an energy state is occupied.
- \(E\): Energy level (eV).
- \(E_F\): Fermi energy (eV).
- \(k_B\): Boltzmann constant (eV/K).
- \(T\): Absolute temperature (K).

## Expected Outcome

Visualize the Fermi-Dirac distribution at different temperatures and observe how temperature affects the transition around the Fermi energy.
